# 📄 ProposalCraft

A modern SaaS platform for freelancers & agencies to create, manage, and send professional proposals — in minutes, not hours.

## ✨ Features

- 📄 **Proposal Builder** — Create structured, professional proposals fast
- 👥 **Client Management** — Store clients, link proposals, track history
- 📊 **Admin Dashboard** — Full control over proposals, clients & content
- 📬 **Contact System** — Manage messages with Unread / Read / Replied status
- 📰 **Blog Management** — Categories, tags, SEO fields, image uploads
- 🔒 **Secure Auth** — Protected admin login & session management

## 🚀 Installation

```bash
git clone https://github.com/irshadsaeed/proposal-craft.git
cd proposal-craft
composer install
cp .env.example .env
php artisan key:generate
```

Configure `.env` with your database, then:

```bash
php artisan migrate
npm install && npm run dev
php artisan serve
```

Open → `http://localhost:8000`
